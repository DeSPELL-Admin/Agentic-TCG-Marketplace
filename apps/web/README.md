# Next.js Web

순백 배경의 카드 탐색·상세 화면입니다. 검색과 실제 카드 미리보기, 무테 갤러리, 가격 요약과 상세 근거 순서로 구성합니다. 페이지는 Server Component로 유지하고 `server/api.ts`에서 `CORE_API_URL`의 Fastify를 호출한 뒤 공통 Zod Schema로 응답을 검증합니다. Emotion을 사용하는 표현 컴포넌트에 DTO를 전달하며 API 주소·환경변수를 브라우저 코드에서 읽지 않습니다.

[디자인 기준](../../design-system/agentic-tcg/MASTER.md)을 `@emotion/styled`로 구현했습니다. `ui-ux-pro-max`의 E-commerce·제목 균형·정보 위계·색 이외 상태 전달 가이드를 참고했습니다. 배경은 사용자 지정에 따라 `#FFFFFF`로 고정하고 코랄은 검색·링크 등 조작에 사용합니다. [이전 코랄 플레이룸 HTML](../../docs/design/archive/coral-playroom.html)은 비교용 보관본으로 현재 UI와 다릅니다.

## Emotion 코드 배치와 SSR

파일 상단에 import·타입을 두고, 컴포넌트를 먼저 정의한 다음 **같은 파일 하단에 styled와 css 선언**을 둡니다. 별도 `Component.styles.ts`로 분리하지 않습니다. Theme 토큰은 `styles/theme.ts`, Theme 타입은 `styles/emotion.d.ts`에서 관리합니다. 스타일 전용 props는 DOM으로 전달하지 않습니다.

`app/providers.tsx`는 ThemeProvider와 `EmotionRegistry`를 조립합니다. Registry는 요청마다 cache를 생성하고 `useServerInsertedHTML`로 새 스타일을 head에 주입합니다. 전역 스타일과 일반 스타일을 분리하고 서버 요청 사이에 cache를 공유하지 않습니다. `GlobalStyles`는 reset·글꼴·포커스·reduced-motion을 관리합니다.

Next.js 16.4.6 / React 19.3.1 / Emotion react 11.14.0·styled 11.14.1에서 개발 서버와 production 빌드의 직접 진입·목록→상세 클라이언트 이동·스타일 유지 및 hydration 오류 부재를 확인했습니다. 향후 라이브러리 업그레이드 시 다시 확인해야 합니다. 일반적인 App Router 전체 호환성을 보증하는 의미는 아닙니다.

## 탐색과 데이터 표시

실제 이미지 URL은 카드 비율을 유지해 표시하며, 누락·요청 실패 시 이름과 세트가 있는 대체 화면을 제공합니다. hydration 전에 실패한 이미지도 복구합니다. Pretendard Variable v1.3.9는 WOFF2와 OFL 고지를 저장소에 포함하고 `next/font/local`로 제공해 외부 폰트 CDN이 필요 없습니다.

현재 API에 맞춰 이름 검색과 둘러보기·피카츄·리자몽·이브이 빠른 검색을 제공합니다. 한 번에 최대 20종이며 조회된 범위에서 이미지가 있는 카드를 먼저 보여줍니다. 세트 필터·전체 결과 수·페이지 이동은 API 계약 확장 후 연결합니다. 설계 미리보기의 로컬 세트 필터를 전체 데이터 필터인 것처럼 적용하지 않습니다.

목록은 카드별 평가·참고 가격 요청을 분리하고 동시 조회 카드를 4개로 제한합니다. 가격 조회 실패가 전체 검색 실패로 바뀌지 않습니다. 사용 가능한 평가가 있으면 데모/시장 USDC 가격을 구분하고, 그렇지 않으면 원본 EUR/USD 참고 가격과 제공자·변형·검증 상태를 표시합니다. 조회 실패와 실제 표본 부족도 구분합니다.

상세의 외부 참고 시세 영역은 `/api/cards/:id/prices`를 조회해 EUR/USD 원본 금액·가격 유형·제공자·관측 시각과 검증 상태를 표시합니다. 가격/판본/환율 근거가 있으면 링크로 제공합니다. 한국어판 실거래가와 구분하며 미검증 가격을 USDC로 표시하지 않습니다. 적정가 영역에는 사용 표본의 최근 관측 시각과 집계 표본 수의 의미를 표시합니다.

목록은 이름·세트·인쇄 언어·대표 가격으로 요약하고 상세 링크에 검증 상태를 보존합니다. 상세에서는 실제 이미지와 대표 가격·원본 통화·검증 상태·갱신 시각을 먼저 보여줍니다. USDC 평가·표본 수·신뢰 수준·평가 출처는 별도 펼침 영역에 둡니다. 없는 카드, 연결 오류 및 가격 표본 부족을 각각 구분하며 평가 요청만 실패해도 카드 속성은 유지합니다.

한국어 표시 이름이 있으면 우선 표시하고 원문명을 함께 보여줍니다. 인쇄 언어는 원본을 유지합니다. 이 표기는 포켓몬 종명이며 한국어판 카드별 정식 제목과는 다를 수 있습니다. 한국어 표기가 없으면 원문으로 표시합니다. DB 데이터는 `pnpm cards:localize`로 채우며 Mock 데모도 기본 카드 3개의 한국어 검색을 지원합니다.

첫 화면은 검색과 실제 카드 한 장의 미리보기를 배치하고 검색 결과 화면은 검색에 집중합니다. 목록은 데스크톱 4열·태블릿 3열·모바일 2열이며, 타일 바깥 테두리와 색 매트 없이 카드 아트워크를 직접 보여줍니다. 상세는 이미지/가격의 2열에서 모바일 1열로 전환합니다. 참고 시세 표는 모바일에서 행별 묶음으로 표시합니다. 검색어는 상세와 복귀 링크에 유지하며, 입력 라벨·키보드 포커스·빈 결과·연결 오류·로딩 상태를 제공합니다.

매물·Agent·정책·거래 UI와 HTTP/SSE BFF는 후속 범위입니다. 개발·시작 명령은 루트 `.env`를 로드하고 `PORT`를 사용합니다. 미설정 시 Next.js 기본 포트인 3000을 사용하며 Core API를 함께 실행해야 합니다.

루트에서 `pnpm --filter @tcg/web test`와 `pnpm --filter @tcg/web typecheck`로 검증합니다.

단위 테스트는 가격 출처·통화·자료 부족·부분 API 실패·검색어 보존을 검증합니다. 실제 브라우저에서 360/390/768/1440px의 목록·상세, 이미지 요청 차단 시 대체 화면, 빠른 검색·빈 결과, 키보드 포커스와 reduced-motion을 확인했습니다. 재현 시 `pnpm build` 후 별도 포트의 `next start`에서도 SSR과 클라이언트 이동을 확인하세요.

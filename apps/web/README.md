# Next.js Web

카드 검색 및 Mock 가격을 표시하는 최소 Server Component 화면입니다. 서버에서 `CORE_API_URL`의 Fastify를 호출하고 공통 Zod Schema로 응답을 검증합니다. 카드 이미지는 이니셜로 표시하며 외부 이미지·폰트 요청이 없습니다.

목록의 카드 이름을 선택하면 `/cards/:id`로 이동합니다. 상세 화면에는 카드 속성, 가격, 표본 수, 신뢰 수준, 출처, UTC 평가 시각과 Mock 안내를 표시합니다. 없는 카드, 연결 오류 및 가격 표본 부족을 각각 구분하며 평가 요청만 실패해도 카드 속성은 유지합니다.

한국어 표시 이름이 있으면 우선 표시하고 원문명을 함께 보여줍니다. 인쇄 언어는 원본을 유지합니다. 이 표기는 포켓몬 종명이며 한국어판 카드별 정식 제목과는 다를 수 있습니다. 한국어 표기가 없으면 원문으로 표시합니다. DB 데이터는 `pnpm cards:localize`로 채우며 Mock 데모도 기본 카드 3개의 한국어 검색을 지원합니다.

블루·화이트 팔레트, 로컬 기본 폰트, 카드 비율의 미리보기를 사용합니다. 모바일 한 열 배치, 입력 라벨, 키보드 포커스, 빈 결과·연결 오류·로딩 상태를 제공합니다.

매물·Agent·정책·거래 UI와 HTTP/SSE BFF는 후속 범위입니다. 개발·시작 명령은 루트 `.env`를 로드하고 `PORT`를 사용합니다. 미설정 시 Next.js 기본 포트인 3000을 사용하며 Core API를 함께 실행해야 합니다.

루트에서 `pnpm --filter @tcg/web test`와 `pnpm --filter @tcg/web typecheck`로 검증합니다.
